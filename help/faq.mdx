Here are answers to the most common questions about AIWA. If you don't find what you're looking for, reach out to the team at [hello@aiwa.codes](mailto:hello@aiwa.codes).

<Accordion title="Does AIWA replace the tools my team already uses?">
  AIWA is a full-stack builder, not a plugin or add-on. It can replace Webflow, Bubble, or other no-code tools for building new projects. It also integrates with tools you already use — GitHub, Stripe, Google, and more — rather than replacing them.
</Accordion>

<Accordion title="Will the AI break my app if I edit it later?">
  No. AIWA's Project Brain™ maintains persistent memory of every architectural decision, data model, and feature in your project. When you request a change, AIWA plans around the existing context — so new features fit the existing architecture instead of rewriting it.
</Accordion>

<Accordion title="How do credits work?">
  Credits are the usage currency in AIWA. Each build, generation, or significant update consumes credits. The amount depends on the complexity of the task and the AI model used. See the [Credits guide](/concepts/credits) for a full breakdown.
</Accordion>

<Accordion title="Do I need to find bugs myself?">
  No. The AI Testing Agent automatically validates every build before deployment — checking layout issues, broken auth, mobile responsiveness, and logic errors. You can also run the Testing Agent on demand at any time.
</Accordion>

<Accordion title="Can I use my own custom domain?">
  Yes. Custom domains are available on Solo, Agency, and Enterprise plans. Connect your domain in Project Hub → Domains, add the DNS records at your registrar, and AIWA provisions SSL automatically. See the [Deploy & Domains guide](/platform/deploy-domains) for step-by-step instructions.
</Accordion>

<Accordion title="Who owns the code AIWA generates?">
  You do. All code generated by AIWA belongs to you. You can export your source code or push it to GitHub at any time. Code export is available on Solo, Agency, and Enterprise plans.
</Accordion>

<Accordion title="Can AIWA really export a real mobile app?">
  Yes. Every app built with AIWA can be exported as a signed Android APK for the Play Store or an IPA for the Apple App Store. There is no React Native dependency and no second codebase to maintain. See [Mobile Export](/platform/mobile-export) for the full process.
</Accordion>

<Accordion title="Is there a free plan?">
  Yes. The Launchpad plan is free forever — no credit card required. You get 45 credits per month, unlimited `*.aiwacodes.com` subdomains, live preview, and version history. See the [Plans page](/billing/plans) for a full comparison.
</Accordion>

<Accordion title="What if my app gets popular and needs to scale?">
  AIWA's managed backend is built on Postgres and served through a CDN. For high-traffic applications, the Enterprise plan includes custom infrastructure arrangements. Contact [hello@aiwa.codes](mailto:hello@aiwa.codes) to discuss your requirements.
</Accordion>

<Accordion title="Can I integrate AIWA with my existing email or calendar tools?">
  Yes. AIWA has built-in integrations for Resend (email), Twilio (SMS), Google (OAuth + APIs), Stripe, Cloudinary, and GitHub. Describe the integration you need and AIWA generates the connection automatically.
</Accordion>
